# TANEM Salon Template — Rules v1

Этот файл — источник правды для производства сайтов салонов из `Shablon-only-for-salons`.
Обычный ChatGPT сначала открывает `START_HERE.md`, затем читает этот файл и `docs/FACTORY_GUIDE.md`. `AGENTS.md` служит дополнительной автоматической точкой входа только для Codex и не является обязательным условием работы обычного Chat.

## Источник клиентских данных

- Агент сначала открывает все доступные переданные ссылки и сам извлекает сведения из Яндекс Карт, Google Maps, 2ГИС, сайта, сервисов записи, социальных сетей, CRM-карточки и приложенных файлов по `docs/INPUT_CHECKLIST.md`.
- Пользователь не обязан каждый раз перекладывать сведения в новую анкету.
- Явный список услуг, цен и длительности, переданный пользователем, является окончательным источником правды для каталога. Данные из внешнего источника можно собрать, если они видны, но нельзя дополнять каталог догадками.
- После исследования агент один раз сообщает, что найдено, и одним списком запрашивает все недостающие обязательные данные и разрешение конфликтов.
- Отсутствующие факты не придумываются. `heroDescription` и `about` уже заданы в `site-data.blank.js` утверждёнными универсальными текстами и не персонализируются без прямого поручения владельца шаблона.
- Необязательный блок без данных скрывается.

## Подтверждённая таблица решений

- Россия (`RU`) → только `ru` и `en`.
- Армения (`AM`) → `ru`, `en`, `hy`.
- Поддержка `UZ` и `TJ` уже существует в коде, но используется только по прямому указанию пользователя; новые страны нельзя добавлять самовольно.
- Мобильные категории услуг: каждое название **целиком в одной строке**, с нормальным размером шрифта и внутренними отступами. Нельзя переносить, уменьшать шрифт или обрезать подписи ради заполнения ширины.
- Для **любого числа мобильных категорий** (в том числе 1–4) использовать естественную ширину каждой карточки, как у Эсмеральды: горизонтальная прокрутка разрешена и предпочтительнее сжатия. **Не растягивать по числу категорий и не заставлять все карточки помещаться на экран.** Эталон CSS: высота 35 px, внутренние отступы слева и справа по 15 px, зазор 8 px, Manrope 12,705 px/500 (ещё на 10% крупнее предыдущей версии, на 21% крупнее оригинала Эсмеральды); название целиком в одну строку. Первую категорию оставить на утверждённой оси первой карточки услуги.
- Мобильная галерея по образцу Эсмеральды: фон за лентой категорий совпадает с основным фоном галереи, без отдельной бежевой плашки и тени; **сама лента обязательно имеет единую видимую рамку-капсулу с радиусом 14 px**. Не путать отсутствие отдельного фона с отсутствием рамки. Категории — крупным шрифтом 13,3 px, каждая в одну строку; при нехватке ширины прокручивается лента, а не уменьшается текст.
- Мобильная карточка мастера: сохраняются размеры и расстояния между вкладками, но последняя вкладка «Отзывы» должна полностью показываться при горизонтальной прокрутке к правому краю, без преждевременной маски или обрезания.
- На мобильной версии первой открывается первая реальная категория. На ПК доступно представление «Все» и реальные категории.
- Нет отзывов → раздел отзывов скрывается. Добавляются только реальные отзывы 5★.
- Нет команды → раздел команды скрывается.
- Есть `masterpc.00000.webp` → он используется справа в первом экране ПК. Нет файла → ПК использует `master.00000.webp`.
- Есть DIKIDI, YCLIENTS или другая прямая ссылка записи → основные CTA ведут к реальному способу записи через штатную механику. Нет прямой записи → используются только реально переданные телефон/мессенджеры.
- Для салона не создаётся и не показывается «стаж».

## Граница шаблона

- Репозиторий хранит только общий каркас, механику, валидацию и правила производства.
- Данные конкретного салона заполняются в отдельном клиентском репозитории.
- Утверждённый дизайн не подгоняется вручную под отдельного клиента.
- Клиентские фотографии не придумываются, не генерируются и не заменяются случайными изображениями.
- Если фотография отсутствует, используется предусмотренный шаблоном fallback или скрывается необязательный блок.

## Канонические имена медиа

Для новых салонных сайтов используются только следующие имена:

- `logo.webp` — логотип салона;
- `master.00000.webp` — главное мобильное изображение салона и изображение блока «О салоне»;
- `masterpc.00000.webp` — отдельное главное изображение первого экрана на ПК;
- `gallery.00000.webp`, `gallery.00001.webp`, `gallery.00002.webp` ... — фотографии портфолио/галереи;
- `favicon-source.png` — системная иконка TANEM.

Новые сайты не должны вводить альтернативные схемы вроде `galery...`, `master.webp`, `masterpc.webp`, `logo.png` и т. п. Старые клиентские репозитории могут содержать наследованные имена, но их не копируют как стандарт.

## Где используется каждый файл

### `logo.webp`

Один и тот же файл используется:
- на заставке загрузки;
- как бренд/логотип в верхней части мобильной версии;
- как бренд/логотип слева сверху в шапке ПК-версии.

Не создавать `logo-mobile`, `logo-desktop` и другие копии.

В `site-data.js`:

```js
media: {
  logo: 'logo.webp'
}
```

### `master.00000.webp`

Это базовое главное изображение салона.

Используется:
- на первом экране мобильной версии;
- в блоке «О салоне» на мобильной версии;
- в блоке «О салоне» на ПК;
- как fallback главного изображения ПК, если отдельного `masterpc.00000.webp` нет.

В `site-data.js`:

```js
media: {
  hero: [
    {src: 'master.00000.webp', alt: {ru: 'Фото салона', en: 'Salon photo'}}
  ],
  about: 'master.00000.webp'
}
```

Добавляйте переводы `alt` для всех языков, обязательных для страны сайта.

### `masterpc.00000.webp`

Используется только как главное изображение первого экрана ПК-версии.

В `site-data.js`:

```js
media: {
  heroDesktop: 'masterpc.00000.webp'
}
```

Если файл не предоставлен, `heroDesktop` оставляется пустым. Шаблон автоматически использует `master.00000.webp`. Нельзя ради этого вручную менять `desktop.js`, `desktop.css` или клиентскую разметку.

### `gallery.00000.webp` и далее

Это единый набор реальных фотографий салона/работ.

Те же физические файлы используются:
- в видимом блоке «Наши работы»;
- в полной галерее.

Не создавайте копию одного и того же изображения специально для портфолио и отдельно для галереи. В `site-data.js` один путь может быть указан в `media.portfolio` и в нужной группе `media.gallery`.

Пример:

```js
const g0={src:'gallery.00000.webp',alt:{ru:'Работа салона',en:'Salon work'}};
const g1={src:'gallery.00001.webp',alt:{ru:'Работа салона',en:'Salon work'}};

media: {
  portfolio:[g0,g1],
  gallery:{
    'Салон':[g0],
    'Волосы':[g1]
  }
}
```

Количество файлов соответствует реальным материалам. Не добавлять пустые карточки или выдуманные фотографии.

### `favicon-source.png`

Это системная иконка TANEM.

- не является логотипом салона;
- не показывается внутри страницы;
- не используется в hero, шапке, галерее или «О салоне»;
- служит источником браузерной/системной иконки.

Не заменять её `logo.webp`, пока отдельное правило не утверждено.

## Порядок нумерации

- Нумерация галереи начинается с `00000`.
- Следующий файл: `00001`, затем `00002` и т. д.
- После публикации существующие имена файлов не перенумеровываются без необходимости.

## Что пока НЕ входит в это правило

Имена портретов сотрудников салона здесь пока не определены, а текущий интерфейс использует штатный нейтральный аватар. Нельзя самостоятельно придумывать новую схему портретов или менять дизайн команды. Персональные работы сотрудника подключаются только по явно переданным путям в `team[].work`. Если отдельное правило портретов понадобится, оно утверждается в общем шаблоне, а не в одном клиентском сайте.

## Обязательный принцип для ChatGPT/технического специалиста

При создании нового сайта:
1. прочитать этот `RULES.md`;
2. скопировать `site-data.blank.js` в `site-data.js`;
3. загрузить реальные медиа с каноническими именами;
4. прописать пути в `site-data.js` по правилам выше;
5. не менять утверждённый дизайн ради конкретных фотографий;
6. запустить production-валидацию и regression checks из `docs/FACTORY_GUIDE.md`.

## Финальный визуальный контракт галереи и портфолио

- Мобильная лента категорий услуг начинается на одной вертикали с левой границей первой карточки услуги; у текущего шаблона это 10 px от края экрана (включая расширение карточек на 15 px относительно контейнера). Не добавлять затемнение/маску справа: владелец отказался от этого предложения.
- При открытии фотографии **из мобильного портфолио** текст «Фото SALON NAME» не показывается; кнопка «Открыть галерею» расположена по центру **ниже изображения**, на одной горизонтальной линии со счётчиком фотографий справа. При открытии фотографии непосредственно из галереи дополнительная кнопка скрыта.
- На ПК счётчик находится сразу под фотографией у **правого края самой карточки**, не внутри изображения. Кнопка «Открыть галерею» расположена по центру ниже фотографии, увеличена в ширину примерно на 2 см (218 px). Шрифт категорий галереи — 14 px.
- Изменения оформления не должны затрагивать категории/время/цены **самих карточек услуг**, тёмные фоны услуг и контактов или данные реальных клиентов. Эталон карточки галереи — `ichAEY/Beauty-Room-by-Esmeralda`.
