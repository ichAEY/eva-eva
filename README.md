# EVA — салон красоты в Павлино

Клиентский сайт EVA, пересобранный 03.10.2026 на актуальном шаблоне `ichAEY/Shablon-only-for-salons` (commit `d9684a534015219c4856a074dc459f89fcd0b413`).

Сохранены клиентские данные предыдущей production-версии: RU/EN, телефон, график, 17 услуг и цены, рейтинг, 15 отзывов и 24 фотографии. Адрес приведён к новому контракту: короткие `salon.city` / `salon.address` для интерфейса и полный `salon.fullAddress`. Для России используются Яндекс Карты через `mapUrl` и `mapEmbedUrl`.

Медиа приведены к текущему стандарту TANEM: `hero.webp`, `profile.webp`, `gallery-01.webp` … `gallery-24.webp`. Подтверждённых данных команды нет, поэтому `team[]` остаётся пустым, а шаблон показывает четыре системные нейтральные карточки «Мастер». Подтверждённого файла логотипа клиента в актуальной версии репозитория нет, поэтому `media.logo` пустой и используется текстовый бренд EVA. Favicon — системный из шаблона.

Цены перенесены из предыдущей клиентской версии и не подтверждены на 03.10.2026. Не изменять прайс без подтверждения клиента.

Резервная версия до этой пересборки: `backup/eva-before-template-20261003`.
